# 编码前准备

**编码前必须执行。**

## 步骤

1. **读取当前阶段产物**
   - 需求文档（PRD）→ 验收标准
   - 设计文档 → 技术方案和接口
   - 实现计划 → 执行顺序和验证方式

2. **发现项目规范**
   - 扫描 `.daedalus/spec/` 目录
   - 识别与当前任务相关的包/模块

3. **定位适用的规范文件**
   - 你改哪个模块 → 读那个模块的规范
   - 你做什么类型的工作（后端、前端、测试）→ 读对应层的规范
   - 阶段产物中引用了哪些规范/研究文件 → 也读

4. **读 index → 读具体文件**
   ```bash
   cat .daedalus/spec/<package>/<layer>/index.md
   ```
   index 不是目标 — 它指向具体的指南文件。按 **Pre-Development Checklist** 读取。

5. **读共享思考指南**（如存在）
   ```bash
   cat .daedalus/spec/guides/index.md
   ```

6. 理解要遵循的编码标准和模式后，开始开发。
